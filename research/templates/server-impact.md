# Txx → S00 的 Server Impact 交接模板

**來源 Task / SRC / CLM：** Txx / SRC-* / CLM-*
**被影響規格：** SPEC-*
**Server 必須更新的可觀察契約：** 描述 Client 輸入、Server 輸出、必要時序/狀態與異常路徑；未知仍寫 UNKNOWN。
**已確認的 Client 原生事實：** 精確有界證據及成立條件（或標註 PARTIAL/INFERRED）。
**Server 自訂的設計選擇：** ADR-*，不得冒稱原版 Server。
**仍待處理：** GAP-* / RR-*、解除條件、owner、優先級。
**需要更新的 TEST：** TEST-* 或 TEST_MISSING 缺口。
**版本影響：** KR/TC、target SHA、是否破壞既有公開契約。
