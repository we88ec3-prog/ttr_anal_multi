## 二、檔案讀取：830040 → 82F850（【確認】）

`830040`（`edi`＝路徑，`[ebp+8]`＝B，`ret 4`）：

1. `714770(path, "rb")` 開檔；失敗則返回（830055..830078）。
2. 經串流物件虛擬函式 `+0x10` 讀 `0x34` bytes 到 `[ebp-0x38]`（`push 1; push 0x34`；830080..83008A），再呼叫其 `+4`（關閉）。
3. 比較 `[ebp-0x18]`（＝緩衝 `+0x20`）與 `3`：相等 → `82F850(B, path)`；否則 → `82F660(B)`（另一格式路徑，**未檢視**）。
   - `82F430` 以預設值初始化檔頭結構：`+0x20 = 3`、`+0x00..+0x1F` 以 `0xC53974` 的字串初始化（`893B59`，緩衝上限 `0x20`；字串內容未讀）。

`82F850(B, path)`：

1. 再次 `714770(path,"rb")`；`82F430` 初始化區域檔頭結構（`ebp-0x540`）；讀 **`0x534` bytes**（`push 1; push 0x534`）。
2. 若 `[B]==0`（尚未初始化）：
   - `B+4 ← hdr+0x24`（整數）、`B+8 ← hdr+0x28`（整數）、`B+0xC ← hdr+0x2C`、`B+0x10 ← hdr+0x30`（以 `fdiv m32` 使用 → float 位元型態）。
   - `B+0x14 ← (float)B[4] / B[0xC]`；`B+0x18 ← (float)B[8] / B[0x10]`；`[B]=1`。
   - （與 `82CBC0` 對 C 的計算一致，見前一份紀錄。）
3. 逐一處理 32 個圖層條目（`i=0..31`，`esi` 起於 `hdr+0x50`、步距 `0x28`；`cmp eax,0x20`）：
   - 條目欄位（相對條目起點 `hdr+0x4C+0x28*i`）：`+0x00`＝int（初始 `-1`，檢查中未使用）、`+0x04`＝**承載位元組數**、`+0x08`＝傳入 `727190` 的長度參數、`+0x0C`＝**dword 個數**（為 0 則跳過本層）。其餘 `+0x10..+0x27` 本次未使用。
   - 讀取 `+0x04` 個位元組到暫存緩衝；配置 `+0x0C × 4` 位元組（含乘法溢位飽和處理）的輸出緩衝；呼叫 `727190`（`ecx`＝來源長度、`eax`＝來源緩衝、`edi`＝`&(+0x08 的值)`、堆疊＝輸出緩衝）。**`727190` 是否為解壓縮未驗證【推測】**（有 9 個呼叫點）。
   - `82FC70(B, i)` 建立 G_i；`memcpy`（`89DBD0`）把 `+0x0C×4` bytes 複製到 `G_i+0x14`。
4. 全部層處理完後呼叫 `82FA80(B)`，關檔，回傳 1。
- 檔頭長度驗算（【確認】算術）：`0x4C + 31×0x28 + 0x10 = 0x534`。即讀入的 `0x534` bytes 僅涵蓋第 32 個條目的前 `0x10` bytes（`82F430` 對每個條目也只初始化前 `0x10` bytes）。條目 `+0x10..` 的 `0x18` bytes 在第 1～31 條目之間如何佈局，本次未驗；**不要把 0x28 當成已確認的檔案記錄大小**。

## 四、D_i（0x30 bytes）的建構：82FA80 → 8330E0（【確認】到呼叫點；`8330E0` 本體未解）

`82FA80(B)`：

1. 先釋放 `B+0x1C+4k`（k=0..31）既有 D 物件（`8333D0`、`833050`、`free`）並清零。
2. 對每個非空 `B[0x9C+4i]`（G_i）：
   - `82FD30` 回傳兩個 2 的冪（`[ebp-0x20]`、`[ebp-0x1c]`）：對 `W/8`、`H/8` 分別找「能整除的最大 2 的冪，上限 `0x80`，預設 1」（已見 128/64/32/16 分支，其後分支未顯示；視為 ≥1 的 2 的冪【推測】）。
   - `tileW = W / p`、`tileH = H / q`（`W=G[0]`、`H=G[4]`，其中 `G[0]` 與 `G[4]` 在此為 `[esi]`／`[esi+4]`；注意 833440 把 W/H 存於 `+8/+0xC`，而 `82FA80` 讀的是 `G+0`／`G+4`，**兩者是否為同一欄位未釐清**，故上述 W/H 對應僅供參考）。

- 與 832DA0 的對應（【確認】欄位使用）：`D[0]`＝磚寬、`D[4]`＝磚高、`D[8]`＝每列磚數、`D[0x18]`＝磚陣列（每筆 16 bytes）、`D[0x1C]/D[0x20]`＝區域指標陣列 begin/end（`833280` 以 4 bytes 為步距讀取）。82FA80 傳入 `{p,q}` 與 `D[8]` 的對應為【推測】，須讀 `8330E0` 確認。
