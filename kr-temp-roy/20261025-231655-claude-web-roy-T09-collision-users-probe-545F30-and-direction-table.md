## 二、方向表 4449D0（【確認】）

- 以 `[0xFB7C18] bit0` 為單次初始化旗標（4DF… 系列常見的函式內靜態初始化樣式）。
- `step = float[0xC55A68] = 0.02454369`（＝2π/256，數值核對）；`[0xFB8820] = step`；`[0xFB8824] = 1/step`（444A66..444A77）。
- 迴圈 `i = 0..255`（`esi` 自 `0xFB8020`、步距 8，終止於 `0xFB8820`）：
  - `[0xFB7C20 + 4i] = i * step`（角度）。
  - `[0xFB8020 + 8i] = F(i*step)`，`[0xFB8024 + 8i] = −G(i*step)`，其中 `F=8FF0A0`、`G=8FEF70`。兩者內含 `fsin`／`fcos` 指令（8FF0A0 內見 `fsin`、8FEF70 內見 `fcos`）→ `F≈sin`、`G≈cos`（【確認】指令存在；其餘 CRT 路徑未逐行讀）。
  - 因此朝向位元組 `h` 的單位向量＝`(sin θ, −cos θ)`，`θ = h·2π/256`；`h=0 → (0,−1)`、`h=64 → (1,0)`。
- `4BB450(float angle)`：`byte = trunc(angle × [0xFB8824])`（x87 截斷捨入，控制字 `|0xC00`）。→ 角度轉朝向位元組。
- `4CA890` 消費端先前讀到的 `[eax*8+0xFB8020]`（`4CAA9E`）即此表；表索引＝actor `+0xB0` 的朝向位元組（先前紀錄已稱朝向在 `+B0`；本次 546100 亦以 `byte [edi+0xB0]` 取得，5461 8B/95）。

## 三、545F30（探測函式；`ecx`＝位置指標，stack：`byte dir`、`float dist`；`ret 8`）（【確認】）

回傳：**1＝受阻（或無碰撞資料）、0＝暢通**（`neg/sbb/inc` 把 82CDF0 的結果反相：82CDF0 回 0 → 本函式回 1）。

1. `[0xFAB1D0]==0` → 回傳 1（545F88..545F94 → 5460E4）。
2. `dist == 0.0`：以 `ucomiss` 與 `[0xC5566C]=0.0` 比較，相等 → 只測目前位置一次：`eax=esi(位置)`、`call 82CDF0`（545FAE）→ 反相後回傳。
3. `dist != 0`（或 NaN）：複製位置到 `[esp+0x14/0x18]`，`dx,dy = dist × 方向表[dir]`；首點＝`pos + 1.5·(dx,dy)`（`[0xC55728]` double ＝1.5），再兩次 `+0.1·(dx,dy)`（`[0xC55898]`，數值 0.10000000149＝float 0.1 升為 double）。共 **3 個取樣點**（`cmp esi,3`）；任一點 82CDF0 回 0 → 回傳 1（5460DE→5460E4）；3 點皆通 → 回傳 0（5460C7）。
   - 即取樣距離相對 `dist`：1.5、1.6、1.7 倍（由 1.5 起、每次 +0.1；算術推得）。
- 呼叫端 82CDF0 為 `545FAE`（單點）、`546058`（迴圈內）。

### 4.2 5464C0（朝向搜尋；`ecx`＝位置指標；stack：`mode`、`float dist`、`byte heading`、`byte* out`；`ret 0x10`）（【確認】控制流程；中段取向細節【未知】）

- `*out = heading`（預設）。
- `mode != 0`：只試反向 `heading − 0x80`，距離 `dist×(1/30)`；暢通 → `*out = heading−0x80`，回 1；否則回 0（54672C..546771）。
- `mode == 0`：
  1. 由方向表取向量、經 `8FEDCA`＋π/2（`[0xC55828]=1.5707964`）＋`× 1/step` 重算朝向位元組並探測；
  2. 受阻時，依 `[0xC5566C]=0.0`、`[0xC55668]=−1.0`、`[0xC456C0]=1.0` 選擇軸向單位向量分量（分支 5465A1..5465CE、546617..546638），經 `D3DXVec2Normalize`（`d3dx9_32.dll`，`[0xBD25F8]` 的匯入）正規化後轉回朝向，寫入 `*out` 再探測（5466 5A..5466 C1）；
  3. 仍受阻 → 試 `heading − 0x80`（5466CF..5466E7）；
  4. 仍受阻 → 逐一嘗試朝向位元組 `0..255`，第一個暢通者寫入 `*out` 並回 1（546700..54671B）；
  5. 全受阻 → `*out = 原朝向`、回 0（54671D..546729）。
- 步驟 2 中軸向分量的選取依據（比較的是哪個值的正負）無法僅由我已讀的部分確定，【未知】；不要據此推斷「滑牆」的方向規則。
