# S00 — 按技能欄位選擇測試動作

使用者明確要求：網頁只切換技能組，不在網頁點擊時播放；例如
「進階1：X：動作184／185」，回遊戲後按技能鍵，避免最小化漏看開頭。
這項要求取代 v81 的頁面單次播放設計；既有完整技能對應與視效驗收不因此通過。

S00 接受以下 SERVER_DESIGN_CHOICE，僅限本機技能空場：

- 按目前角色、配置、階段及實際按鍵顯示技能名與動作下拉選單。
- 原有候選編號照列；同角色、同家族的其他資源列為待比較，其他資源列為未確認配對。
  家族順序不等於技能ID，更不把使用者的手動選擇發布為已證實綁定。
- 選擇以角色內的 Practice ID 保存，不按單一 X 槽保存，避免 V／Tab 更換技能時套錯。
  同一技能在不同配置共用選擇；換角色清空網頁選擇。進階階段的按鍵規則沿用既有測試場。
- 套用重建測試技能組但不送000D動作；只有遊戲收到合法技能鍵、通過既有條件後才播放。
  v81 的 PlayPreview 頁面入口與執行分支移除。原始單動作模式仍可套用後回遊戲按Z。
- MotionOverrides 僅接受已有該角色資源白名單中的動作與該角色 Practice。
  動作比較只允許空場；不改技能ID、來源數值、冷卻、正式資料或 Client 檔案。
  選定一個動作後不自動輪替其他候選，普攻選擇亦作單動作比較。
- 暫沿用該槽現有比較時長；原先未指定動作的槽採資源預覽保守等待。
  不以這個等待時間證明原版取消窗、連擊窗或效果持續時間。

驗證分開涵蓋：套用無自動動作、Pipa進階1／X分別選184及185、遊戲X送出所選編號、
不改耗量與其他槽、V／Tab選擇傳遞、九角色合法動作可進入其進階X比較。
網頁顯示、實際完整動畫與特效、技能對應及正式技能玩法仍分開驗收。
