## 本輪找到並修正的 Server 連擊問題

目前 prototype 的 Input 在 IsCasting 時只更新 held flags 就返回；動畫期間再次正常
按下／放開普攻會遺失這次按下，Poll看到最後held=0便回待機。連續按鍵因此無法可靠續段。
新候選保留一筆普攻按下，在本段結束時消費，直接接下一段；移動意圖會清除此保留，
最後沒有保留／新鮮held輸入時回正常停止。另將命中朝向固定為本次開始施放的方向，
避免後來更新輸入方向改寫已開始攻擊的命中朝向。

這是 **Server重建策略**，不是已恢復官方buffer／取消窗口。現有101…107候選、
固定impact200ms、HP／傷害／範圍與冷卻仍有 prototype 限制，不能因這次修正就全數驗收。
13個HappyPath案例通過，既有首戰列改為按下→放開→動畫中再按／放開→段末接102候選→
第二次命中→停止→第三擊勝利→返回與蘋果招募。該測試不執行Client，也不證明原生動作長度。
v4尚未換版；將整段可用戰鬥修正準備好後再安排人測，避免每個小變更重走教學。
