# S00：普攻末段接技能的輸入暫存候選

追蹤既有 REQ-0016 戰鬥優先；不是新增使用者回報或 CODE_ANALYSIS 原生主張。
本輪直接檢閱私有 Server 當前 Input／Poll 實作，發現 action deadline 存在時僅保存
普通連擊按鍵，X 或 Z+C 直接回空陣列；若玩家在動作結束前短按再放開，後續 Poll 不會施放。
這是目前 Server 的行為缺口，不是證實 Client 沒送鍵，也不是新的官服 cancel window 分析。

## 實作選擇

- 暫存最新一次技能按下的選擇與 monotonic timestamp；一般放開不清掉這次按下。
- 只在目前動作自然結束後消費，限最後 0.4 秒內的新按鍵且當下未要求移動。
  這個期限是 Server 自訂候選政策，不是 ASD clip／Effect Delay 推出的原版窗口。
- 實際 Start 仍查當前冷卻與 SP／MP，成功開始才扣資源、記冷卻及發 action。
  暫存本身不取消當前招式、不扣費、不重設冷卻，也不發提前命中。
- 移動要求清暫存；戰鬥全怪死亡返回時清暫存。技能未開始時維持既有普通接招／停止處理。
  沒有新增無限佇列，也未恢復完整官服取消、連段、輸入優先序或技能規則。

## 驗證與限制

兩個正常案例：伊莉西亞普攻 0.5 秒時短按 X 或 Z+C，再放開；到 0.8 秒普攻結束時
只產生一次對應 108／109 action，扣對應 SP／MP，技能結束回 idle 且不再扣費。
使用空白位置隔離命中影響，避免「打死怪直接返回」掩蓋接招檢核。
19 個 HappyPath 合成案例通過，沒有執行異常／邊界／重播／故障／併發等暫緩測試。
