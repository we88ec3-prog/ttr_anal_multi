結算畫面使用本場實際入帳量。累計經驗接近 Client 欄位可表示的上限時，獎勵以剩餘容量為限。到達上限後仍可通關並返回，畫面回報本場新增 0。Server 在同一交易保存設定獎勵及實際入帳量；再次處理同一場時沿用原入帳量和角色目前累計值。既有紀錄若沒有實際入帳欄位，沿用當時發布的設定值。這是 Server 的結算規則。一般帳號的實機結果仍以 TS-37 為準。

Stage 1 進行中若收到既有的離隊請求，Server 結束這場未完成副本，返回馮德斯的無隊伍場景。Server 在切換村莊前先送停止移動與姿勢更新，再清除未撿取的地面物件。未完成場次不發結算，也不入帳本場暫存的擊倒或清場經驗。重新建隊後從節點 10 開始，已存主線與先前入帳的經驗保留。合成驗證在清完第一圖且持有暫存經驗時離隊，核對返回後重開的場次從零累計。Client 在副本內是否提供可觸發該請求的介面，留待後續實機確認。

最後出口已接受時，Server 在處理該次按 Z 的請求內，用場次 ID 寫入通關經驗，再傳結算頁。這樣在下一次世界更新前登出，也能保留已完成且入帳的場次。如果本次未取得入帳結果，世界更新可用同一場次 ID 重試。合成流程第一輪沿用隊伍返回，第二輪在結算頁確認前離隊，以同一角色核對兩次經驗各增加一次、背包各增加一張卷軸，以及保存的主線進度相同。
