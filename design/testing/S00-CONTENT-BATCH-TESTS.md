# S00 關卡功能批次測試表

本表是人工測試的單一入口。只執行「待測」列；「通過」不重測，「未開放」不能當成可測。
合成測試與人測分開記錄。本批 Server 為 v96a；優先沿用可正常啟動的既有 Client，回報時記錄實際版本。
不修改 Client；所有內容定義為 NOT_NATIVE_MEF。測試模式不提交正常主線、EXP、道具或獎勵。

共同準備：已完成教學且持有伊希莉亞與蘋果的既有本機測試帳號登入並進廣場，重新整理本機進度測試頁，使用「關卡內容／AI測試場」。不用重跑新手教學。帳密及本機部署識別不放公開表。
分支每張圖只有一隻20HP怪，正常靠近按Z清怪，再到點上按Z；本輪不按V／Tab。
