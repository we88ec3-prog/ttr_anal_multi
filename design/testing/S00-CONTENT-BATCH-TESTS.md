一般副本進圖時以一份 `0027` 登記該節點的所有出口，初始狀態為關閉。清場只提交一次，之後仍持續評估出口條件。Server 以 `0048` 發布實際開啟的出口，並用請求鍵、開啟狀態、角色位置和碰撞判定能否通行。合成第一圖另加入清場後一秒的出口條件，正式五圖配置未加入該延遲。分支出口與條件的畫面及操作仍待 Client 驗收。

一般副本亦使用共用的手動互動點。進圖時與出口一起登記，Server 以 `001C/category 1` 處理操作，更新關卡旗標與 `0048` 狀態。配置的障礙會套用到該場的移動、戰鬥、出口與掉落判定。合成第一圖新增一個必須清場後操作的互動點，確認單靠清怪與延遲仍不會開出口。正式 Case 1 沿用既有配置。

馮德斯 Stage 1 的直接攻擊以該圖 BND 判定攻擊路徑，玩家與怪物都不能隔著靜態牆面命中。合成牆面先核對雙方血量維持原值，再移到同側核對雙方可命中。這是 Server 碰撞規則，傷害數值與原生 MEF 仍各自驗證。

一般副本每次戰鬥更新先依已收到的方向輸入推進 Server 角色位置，再計算怪物攻擊落點。合成測試讓玩家在近戰起手後維持同一方向，於命中時刻前走出攻擊距離，確認無傷害封包且停下時位置已更新。TS-37 可在自然戰鬥中記下已走開仍受擊的情況，實機手感及畫面仍待確認。

Stage 1 出口在清場條件成立後更新可用狀態。此時保留玩家現有的走路與攻擊狀態，避免出口亮起時打斷正在走的角色。合成測試在出口開啟前按住方向，核對開啟封包與移動狀態。實際操作出口仍需到範圍內按 Z。

多品項掉落先由合成流程驗收。測試設定讓地圖 19 的頭目同時掉一件裝備和一張復活卷軸。首輪分兩次按 Space，核對兩件各自入包；第二輪卷軸已達測試上限，按一次 Space 應撿到裝備，卷軸留到結算清除。兩輪回村後核對裝備 ID、卷軸數量及經驗。TS-37 的正式 Case 1 設定仍只有一張復活卷軸。多品項實機驗收需另載測試配置。 [掉落配置](../scenario-content/GROUND-LOOT.md)

以原版地圖 19 的 `mushroom12.bnd` 核對頭目配置點 `(376,336)`。從該點沿八個方向取距離 11 的位置，每 0.25 單位核對兩層靜態碰撞，八條直線皆可通行。以北側撿取點 `(376,325)` 為例，出生點 `(364,140)` 到該點有 197 步的四鄰接路線，再走 216 步可到出口內側 `(392,525)`。此檢查只驗頭目配置點周圍，頭目追擊後的實際落點仍依擊倒位置判定。

TS-37 的地圖 2 起點變體留待實機。部署這個變體時，健康頁應仍為 Case 1，使用變體的設定雜湊。正常建隊開始後，依序核對地圖 2 → 5 → 9 → 13 → 19；頭目、掉落及回村驗收步驟同 TS-37。離線已使用原版碰撞走完五圖，選取頭目掉落並產生待結算經驗。 [地圖 2 起點配置](../scenario-content/PHINDOS-STAGE-ONE.md#case-1-的地圖-2-起點)

雙出口變體實機待測。載入雙出口配置後，同一角色跑兩場。第一場清完地圖 9 選較遠的出口走地圖 13，第二場選較近入口的出口走地圖 17。每場都應能前往地圖 19 擊倒頭目、撿取並結算回村。兩條路已分別離線驗證，出口顯示、入包與經驗入帳仍需 Client 驗收。 [雙出口配置](../scenario-content/PHINDOS-STAGE-ONE.md#地圖-9-的雙出口)

地圖 3 起點變體已離線驗證兩條路線。載入該變體後，TS-37 應核對首次進圖為 3，清場後依序進 6 與 9。分支、頭目、掉落及回村的驗收步驟沿用雙出口變體。 [地圖 3 起點配置](../scenario-content/PHINDOS-STAGE-ONE.md#case-1-的地圖-3-起點)

Case 2～4 可另選地圖 2／3 起點。離線已走完四個 Case 的 20 條圖表路線。實機依載入的 Case 與起點核對分岔圖、兩個出口、分支圖及終點，正常建隊、拾取入包與經驗入帳沿用 TS-37。 [Case 2～4 的路線表](../scenario-content/PHINDOS-STAGE-ONE.md#case-24-的雙出口配置)

TS-37 換版預檢可從 `/health` 的 `localStageOne.entryNode`、`entryMap` 核對實際載入的起點。維護者的預檢工具會從指定 JSON 取入口，連同 Case 與雜湊一併比對。正常場次的本機測試頁會保留本場受理拾取筆數，切圖後累計，結算畫面可與本場實際入帳經驗一起核對。筆數以 Server 成功受理的拾取操作計算，數量及品項以遊戲背包核對。下一場從零開始。現行定義的經驗在最終出口結算時入帳。
