# 持續占點旗標

節點的 `signals` 可設定 `RegionHeld`。Server 依角色估計位置觀察圓形區域，首次觀察到進區才起算，滿指定秒數後設立旗標。即使發生在兩次週期更新之間，移動報告或技能位移讓 Server 觀察到出區時，仍會重設未完成的計時。角色倒下或主線提交清場時，未完成的計時也會重設。主線演出期間不計入占點。

```json
{
  "flag": "exit-gate-open",
  "event": "RegionHeld",
  "region": { "x": 379.5, "y": 399.5, "radius": 2 },
  "delaySeconds": 2.5
}
```

時間範圍為 0.25 至 3600 秒。完成後旗標在同一副本保留，離開區域不會復原。增援、互動點、傷害區或通行屏障可引用此旗標。出口仍須滿足既有的清場與其他條件。區域以 Server 依輸入估計的位置判定，實機的畫面與 Server 座標仍須對照。
