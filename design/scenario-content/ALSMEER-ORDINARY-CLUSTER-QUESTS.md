## Server 進場規則

一般單人狩獵開始時，以所選 Stage 與任務的 Accepted 狀態選出追加群組。同組多筆任務共用一次出場。換圖沿用入場選定的群組，擊倒分別更新當前有效的任務。下次新開副本會重新讀取進度，當群組對應的任務都已 Ready 或 Completed，就恢復原本的遭遇與擊倒經驗。追加群組走既有清場及結算流程，原先的必殺首領維持指定 Model／PRE。

## 離線驗證

兩個全新帳號分別載入爾勒梅斯 Cases 699／701／703／705 及 700／702／704／706，均帶 Case 315。每組以原版 BND 和暫存 SQLite 完成 41 場爾勒梅斯狩獵，包含各一場 Stage 467 及四場 Stage 145。檢查器核對追加位置可走到、每張怪物 Model／PRE 與數量、擊倒 EXP、任務達成通知、Q31 背包報酬、NPC 10053 的 Q136 後交付，以及重登快照。Q11 首場重登由普通及大型蒂奇共取得兩件，Q39 仍為一件。

兩組 Stage 465 前八場結算依序為 152、七場 144 EXP，之後回到 136。Stage 466 前八場 170、之後 160。Stage 468 首場 244，接著七場 232，之後 208。Stage 145 前三場 268，第四場回到 244。這些差異是 Server 配置的追加擊倒經驗，既有結算值照常累加。每個帳號新增七項交付合計 7,450 EXP、4,833 LeeLoo，最終各完成 **81 項普通任務及 Q144**，存於圖 199、Lv.19／326,944 EXP。指定 v2 的實機畫面與操作列 AQ-22／23。
