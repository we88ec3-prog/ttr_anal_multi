# 商品管理篩選、價格入口與簡易翻譯

2026-11-20 使用者要求商品管理增加角色／部位／種類（裝備、道具、服務）篩選，
說明如何編輯價格，並把韓文道具名稱做簡易翻譯。這是既有管理端的限定續作，
不接續其他已暫停的 MEF／副本或商品效果開發。

## 來源與分類

[管理端投影](kr-cash-admin-browse.json) 包含既有目錄全部 2,225 個 Product。
[建立工具](../../governance/client-variants/20261120-cash-browse/build_browse_metadata.py)
先核對現用 Table.stp、原 Product／ItemTable2 member、既有標籤／商品目錄及
archive reader 的固定 SHA，只讀取既有資料，不修改原件或 Client 資源。

角色來自 Item 的 USE_LIMIT char，沒有角色欄位的商品顯示「通用／未指定」。
選擇特定角色時包含這類未限定商品；不把名稱猜測當成新的角色准入規則。
髮型／染髮依原 Item 使用限制取角色，不能沿用只針對時裝的舊 requiredRole=0。
例如 6407 為角色1、2364 為角色8；此投影只供管理篩選，不改遊戲資格或效果。

部位由 EQUIP_POS_LIST 投影：武器1、頭飾6、背飾7、腰飾8、臉飾9、武器外觀10、
服裝外觀11。另設「髮型／染髮」（class38/39 的管理分類）與「無裝備部位」。
有裝備位置者歸裝備；class30 的原直接效果類歸服務；其餘歸道具，包含禮包、
消耗券、髮型及染髮用品。這是管理分類，不把未實作服務或商品開放。

## 管理名稱簡譯

保留既有中文／英文標籤。1,142 筆含韓文名稱使用人工編輯的
[簡譯詞彙](../../governance/client-variants/20261120-cash-browse/simple-zh-glossary.txt)
組合產生繁中名稱，專名可能採簡易音譯，明示非官方譯名。建立工具對未覆蓋韓文
詞彙停止產出，不用 Product 編號或泛稱假裝完整翻譯。新投影的 displayName
均不含未譯韓文音節；原名保留，列表顯示「簡譯；原名」，中韓名稱均可搜尋。

沒有直接套用同 Product／Item 的台版名稱：同 ID 仍可能在不同版本代表不同
內容，不能只按數字認定語意相同。本批也不把管理端簡譯寫進 Client XML。
配套只將簡譯及 originalName 放入管理標籤；XML EXPLAIN 等原欄位保持模板值。

## 篩選及改價流程

商品目錄與價格草稿共用相同三項條件，並與名稱／Product／Item 搜尋交集。
分頁、商品的「編輯價格草稿」連結、建立草稿、價格／列表儲存、封存及販售
控制返回時保留條件。種類使用 category 欄位，與既有草稿 COST／LIST 的 kind
操作欄位分開，避免互相覆蓋。各條件先核對固定選項再用於顯示。

商品管理每列新增「編輯價格草稿」：選擇或建立草稿，找到該商品的價格選項，
修改 Garnet 數字並按「存入草稿」，核對差異後產生固定版本配套 ZIP。
頁面提供這些步驟，現用目錄價格與草稿基準仍分開。草稿不直接改線上價格；
同包 Mall XML／Server 目錄／管理標籤成組發布並重啟後才生效，沿用
[既有配套流程](CASH-EXTERNAL-CATALOG-RELEASE.md)。

## 驗證範圍

正流程核對真實 metadata 的角色／部位／種類交集、通用商品、髮型角色及中韓
搜尋。隔離 HTTP 驗證五組條件、分頁、商品改價入口、建立草稿、1541 改333、
儲存返回、正常停賣／恢復及配套匯出。管理標籤含簡譯／原名，Client XML 名稱
保持原模板。瀏覽器實際控制項與改價入口已觀察，截圖保留本機 outputs。
隔離範例不寫玩家資料或發布測試價格；Client 遊戲畫面與既有延期套件仍分列。
