## 第三層碰撞位圖

`erode07.bnd` 與 `erode11.bnd` 是 v2，分別有 768 × 768 與 1,024 × 1,024 格。第三層的展開長度和格數與前兩層一致，DWORD 值皆為 0 或 1。第三層分別在 9,810、12,113 個前兩層皆為零的格子標記 1。

Server 僅對這兩個精確 SHA-256 接受第三層，將任一層非零的格子設為阻擋。此為 Server 對走格的保守規則，第三層在原版的作用仍待確認。圖 1102 原候選出口因此不可達，已移到同一連通區內的 `438.5, 292.5`。兩張圖的怪物與出口皆重新按三層核對可達性。

使用原版 BND 的離線流程已驗證五圖、場景命令、結算、圖 1086 轉場與 Q441 存檔。樣本維持 Lv.32、最大 HP 1,275，經驗累計至 2,224,912。指定 v2 的實際碰撞、轉場與 NPC 操作待驗。
