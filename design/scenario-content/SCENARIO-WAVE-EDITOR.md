# 波次編排介面

此擴充使用既有 `LocalScenarioWave`，不新增原生 MEF 格式或封包。
主線、一般狩獵場與 RAID 的二維編排頁可選擇／建立／移除順序、定時增援，
調整同類次序、識別、延遲、必要旗標及圓形觸發區域。

順序波次依陣列次序，在前組清除後開始倒數；定時波次依本圖戰鬥開始計時。
延遲到達後仍須滿足所有必要旗標與當前位置區域條件。這是既有 Server 候選
語意，不是官方原生腳本認定；支援範圍仍以共用內容執行器為準。

新增波次複製已選取的普通怪物（沒有選怪時採本圖第一隻普通怪物），不自動
複製必要頭目。新怪物沿用模型、AI、PRE、EXP、巡邏等資料，可再由物件清單
編排；不憑空指定新的模型。兩類波次合計至多31組、全圖至多255隻的既有限制
維持。未保存編排只改同頁 JSON；保存／匯出仍經同一來源、圖序、AI、條件及
原 BND 驗證，不自動發布或更換遊戲服務。

改名會同步本圖明確引用該波次的頭目、掉落與訊號 `waveId`，不改旗標名稱。
RAID 必要頭目的來源波次識別保持固定。仍被頭目、掉落或訊號引用的波次不從
簡易介面刪除，須先在 JSON 調整引用。沒有引用的波次可整組移除。
必要頭目未顯式填 `waveId` 時，也以該波次中的模型／PRE 成員判定保留，
不把缺少顯式識別視為可直接刪除。
觸發圓形在底圖顯示，中心可由波次欄位或點位編排調整；完整靜態可達性由
伺服器檢查。旗標的定義／相依機關仍在 JSON，這不是全部規則的圖形化工具。

既有關卡／AI 同版保存、歷史及精確配套匯出保持。手動改 JSON 後須重新載入
圖面，避免與圖形修改互相覆蓋。Client 原件、玩家資料與原生 MEF 缺口不變。
