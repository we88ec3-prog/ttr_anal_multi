# 地形傷害區

主線關卡節點的 `hazards` 可定義最多 16 個圓形傷害區。每區有唯一 ID、中心、半徑、固定傷害及週期。選填 `disabledByFlag`，可由同一副本的計時、清除波次或互動事件停用該區。

```json
{
  "id": "floor-trap",
  "region": { "x": 383.5, "y": 401.5, "radius": 3 },
  "damage": 25,
  "intervalSeconds": 1,
  "disabledByFlag": "trap-disabled"
}
```

Server 第一次觀察到玩家在區內時開始計時，經過完整週期才扣血。觀察到離開即重算，停格後一次更新最多結算一輪。重疊區各自計時。旗標生效、戰鬥清場或換圖後，該區停止傷害。清場前若仍有未出場的增援，傷害區仍按設定運作。

每次傷害介於 1 到 500，週期為 0.25 至 3600 秒。環境傷害目前使用固定值，不觸發敵方攻擊閃避、格擋或受擊回復。Server 更新 HP，並沿用受擊及倒下處理。傷害無施放者，故不送帶來源的命中封包。陷阱外觀、傷害跳字與原生 `.mef` 消費流程仍待來源驗證。
