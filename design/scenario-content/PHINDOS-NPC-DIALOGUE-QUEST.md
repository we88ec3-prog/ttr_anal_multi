# 馮德斯 Q2842 任務種類教學

在已核對的韓版 `QuestInfo.xml`，Q2842「퀘스트 종류」為 type 1／subtype 4、Town 1、Lv.3，沒有 Field 或前置任務。接取與交付 NPC 都是 10002「라제드」。AcceptAction 是 type 3／param 10，CompleteAction 是 type 1。Content 2938 要與拉傑德對話。原表報酬為 700 EXP 及 1 點公會地區名聲。

`QuestTalk.xml` 列接取前 31660、接取後 31662、交付 31667。馮德斯對話說明 NPC 頭頂的任務圖示與主線任務順序。原表沒有擊倒、收集、購物或地圖切換條件。 [原表雜湊與普通任務 UI](PHINDOS-ORDINARY-QUEST-2843.md)

## Server 候選流程

1. 在正常馮德斯場景靠近 10002，沿用 `0036/QID` 接取。核對角色等級、NPC 位置與前置狀態，保存 Accepted 並回覆既有 `0040`。
2. 以現有 `001C/category 3/NPC 10002` 候選互動判定對話。若當前主線使用同一 NPC，沿用主線優先。主線交接完成後，返村對話使 Accepted 轉為 Ready 並回覆 `0045`。這一步可重登保留。
3. Ready 後再次互動，SQLite 同筆保存完成與接取角色的 700 EXP，再發布 `0046`、前置快照與角色經驗。本任務沒有物品或貨幣報酬。公會地區名聲待接入。

對話達成與交付都經過正常場景及 NPC 授權。封包順序屬既有 Server 候選，指定 v2 的手冊 UI、對話回報與交付畫面另驗。Q2840 明列「點擊世界地圖」為目標，Q2857 明列「銀行利用」按鈕，兩者仍需各自的 Client 事件證據。Q125 與 Q128～130 的先決鏈包含原表 Lv.120 的 Q37／Q127，依原表保留。

## 離線驗證

兩個全新帳號分別用一般與輪替關卡 Case，於 Q124 後接受 Q2842，走完同 NPC 的 Q131／132 主線交接，再走正常單人隊伍入口回馮德斯。Q2842 保持 Accepted，返村先對話達成，重登後仍為 Ready。回 10002 交付後核對 700 EXP、背包與錢包無增減，以及 Q132 保存點與下一段主線。重登後的前置快照包含 Q2842。兩組均完成 87 項普通任務及 Q144，存於圖 199、Lv.19／333,742 EXP。指定 v2 待 AQ-27。
