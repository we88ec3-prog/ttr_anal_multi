## 編排契約

每個定義至多64個唯一旗標，名稱以 ASCII 英文字母起首，後接英數字、
底線、點或連字號，全長1～64。必要旗標至多16個；編輯欄位以逗號、
中文逗號或換行分隔，去重後保存。以下十種事件沿用既有執行器語意：

| 事件 | 可編輯參數 |
|---|---|
| GroupCleared | 本圖全部怪物組清除 |
| RegionEntered | 圓形區域中心與正半徑 |
| CheckpointInteracted | 互動鍵、圓形區域、清場要求、必要旗標、可選標記鍵與半徑 |
| ClearDelayElapsed | 清場後延遲，大於0且至多3600秒 |
| WaveCleared | 本圖初始怪物組或具名增援 |
| WaveHealthReached | 同上，剩餘血量1～99% |
| NodeDelayElapsed | 本圖開始後延遲，大於0且至多3600秒 |
| RegionHeld | 圓形區域、持續0.25～3600秒 |
| BossDefeated | 本圖既有必要頭目；不能藉此新增或改寫頭目來源 |
| BagQuantityReached | 非零 uint Product、數量1～255；觀察已提交背包，不消耗道具 |

事件切換清除互斥參數，保留其他未編欄位；隱藏的輸入欄位停用，避免其
瀏覽器數值約束阻擋另一種事件保存。幾何、來源、依賴、商品來源、互動
容量與標記衝突仍由既有完整驗證器裁決，介面不取代後端驗證。

改名同步同一定義所有節點中的波次、互動及出口 `requiredFlags`，以及
屏障 `opensWithFlag`、傷害區 `disabledByFlag`；不改其他定義的同名字串。
仍被上述欄位引用的訊號不從簡易介面刪除。完整 JSON 可編進階規則，
但必須先重新載入圖面才能繼續圖形操作。

主出口與各分支出口各自編輯必要旗標及可選觸發圓形，保留出口鍵、座標、
半徑、路由與目標節點。兩欄皆空表示清除額外 condition；既有清場規則
維持。出口區域與訊號／互動區域也在地形圖顯示，可由物件欄位移動中心。
保存建立新版本，匯出仍需通過全套來源／AI／靜態地形檢查；不自動發布。
