# 失落要塞 Q258／Q259

韓版 QuestInfo 的 Demand 為 Q257 → Q258 → Q259 → Q260。Q258、Q259 均由 NPC 10057 開始，建議 Lv.27。Field 48／Case 124 只有節點 1，對應圖 909、地形 `town004N` 和碰撞 `town004.bnd`。Q259 原表列 90,318 EXP、3,276 LeeLoo；type 3 的 200 用途待核對。

| 階段 | Server 候選 |
|---|---|
| 與 NPC 對話及編隊 | Q258 Scene 1。Q259 Scene 1 使用空地圖參數。 |
| 進圖 | 依序播放 Q259 Scene 2、3，再交還操作。第一波為 1016、1017、1102，均為 153 HP。 |
| 順序增援 | 前一波打完約 1 秒生下一波。第二波為 1093、1105、1094，其中必要頭目 1105 為 663 HP，與兩隻普通怪同場。第三波為 1049、1050、1051，各 153 HP。 |
| 清場及回村 | 清完三波才播放 Scene 4、5 並開出口。按 Z 進結算，確認後播放 Scene 6 並返回圖 510。 |

Scene 2～5 都載入 `town004N` 後還原地圖。Scene 3 引用 1105，Scene 4 引用 1049、1050、1051。Chart 只定義一張地圖，Cluster 有六組可用名單。上述演出與戰鬥的分界、各波名單、頭目所在波次和出生點為 Server 配置。怪物模型取自群組 2、3、4，各波名單有調整。原版的逐段觸發、生成條件及完整數量仍待取證。
