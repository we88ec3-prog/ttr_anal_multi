## Server 進度與驗收

1. **接取。** 從正常馮德斯場景核對角色等級與接取 NPC 的互動上下文。先存一般任務的 Accepted 狀態，再發布接取 UI。暫定以冒險團保存普通任務，並記錄接取時的角色。既有主線 revision 繼續由主線紀錄管理。
2. **達成。** 實機先分開按「狩獵場選擇」與「確認難度」。若只有確認有發包，可用 Server 已驗證的 Stage 選擇作為候選完成條件，並保留 Client 提示只要求點按鈕的差異。若找到面板開啟的獨立可驗證請求，按實際事件調整。此階段應只轉 Ready，留待 NPC 交付。
3. **交付與獎勵。** 核對實機回 NPC 10008 時送出的請求。在同一次交易檢查 Ready、有效會話及背包可放入資格，保存完成旗標、經驗和三張物品獎勵，再發布角色及背包更新。公會地區名聲維持獨立欄位待接；擁有其他角色、重登或切換舞台不重複給獎。完成旗標加入既有 `006F` 快照，保留主線與教學的其他 keys。原生交付按鈕與 active quest 快照仍需取證。
4. **批次 AQ-01 待取證。** 在正常馮德斯、Lv.4 以上且 Q2843 可見的帳號，依序打開 NPC 10008 任務清單、選 Q2843、按接取、打開狩獵場面板，再確認 Stage 462，分別記錄畫面及時間。之後回 10008，記錄交付按鈕是否可見與動作。比對 `001C`、`0036`、`0039`、`003C`、`0064` 的實際順序；`003C` 記錄全長 8、僅留前四位元組。這張卡用於取證，完整接取、交付、獎勵與重登的實機驗收仍待實作。
