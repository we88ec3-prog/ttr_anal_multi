# 波次血量階段

`WaveHealthReached` 讓 Server 關卡在指定波次降到一定血量時設定旗標。旗標可觸發定時增援或開啟互動點。整場清場及結算仍走既有流程。

```json
{ "flag": "phase-two", "event": "WaveHealthReached", "healthPercent": 75 }
```

- 省略 `waveId` 或設為 null 代表入場波。具名值只引用同節點的順序或定時增援。尚未生成的波次沒有血量觀察。
- `healthPercent` 接受 1 至 99 的整數。比較使用該波全部成員的 Server 現存 HP 總和與其最大 HP 總和，包含已倒下成員的最大值。等於門檻即成立，一擊跨過門檻也會成立。
- Server 在戰鬥傷害結算後檢查血量變化，再檢查後續增援。旗標只設定一次，且只在當次實例保留。低於門檻仍存活的怪物保留自己的 HP 和行為設定。
- 載入時驗證旗標的波次依賴，避免波次等候自身或尚不可達的血量訊號。順序增援仍等目前存活怪物清空；需要和原波同時交戰時使用定時增援。

圖 193 的獨立場景使用 80 HP 的入場怪。一次 20 傷害把它降到 75%，即觸發一隻 20 HP 增援。這些是測試值。兩隻怪都倒下後，才可從出口進入測試結算。內容使用 `NOT_NATIVE_MEF` 格式。 [JSON Schema](local-scenario-definition.schema.json)
