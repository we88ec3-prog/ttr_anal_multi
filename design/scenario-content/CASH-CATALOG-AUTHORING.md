# 商品列表與價格草稿

使用者最新用途為朋友私人遊玩／交流，不需要退款或真實現金流。本輪只做虛擬商城的實用設定；舊退款程式及歷史保留，後續不再擴充或安排人工退款驗收。

2026-11-19 接續商城管理缺口。商品畫面依 Client 資源，Server 另持固定目錄；沒有已證的動態全列表封包。因此先完成 Server 自有草稿、版本、差異與提案匯出，不直接改 Server 收費，也不製作或修改 Client 載入資源。

## 基準與草稿

唯讀投影 `build_authoring_baseline.py` 核對原版與現用 Table.stp、CashProduct member、archive reader 及 Server 目錄 SHA。每個 Product 取現用列，現用沒有則取原版模板；保存來源表、ElementTree 列表示雜湊、完整價格選項與 Server 映射／支援旗標。列表示不是原檔位元組範圍，也不是已生成的新 Client 列。2,225 個模板皆有明確價格映射。

管理端可建立具名稱／原因的草稿，編輯指定價格選項與「是否列入 Client 商品表」的目標狀態，回復基準、封存並查看版本／最近修改紀錄。價格與列表草稿不開放未實作商品效果；提案會列目前 Server 功能支援狀態。新增列只限已有原版／現用模板，不憑空猜 Row 或 Product。

每次修改帶預期版本與 request ID，在同一 SQLite 交易追加稽核及更新草稿。編輯為基準值會移除該差異，仍保留修改歷史。基準 SHA 改變時舊草稿只讀，不默默套到另一版。列表是否包含該列不等於所有 Client 篩選／畫面都已驗證。

## 匯出與配套發布提案

匯出為 `LOCAL_CASH_CATALOG_PROPOSAL_V1_NOT_NATIVE_MEF` 的 `.cash-catalog-proposal.json`，保存來源、草稿 ID／版本、每筆前後值與原因、模板列身份、目前功能支援狀態及配套發布要求。相同版本內容可重現，下載顯示 SHA。這不是 `.cash-shop.json` 或 Client XML/STP；不包含可直接啟用的目錄，也沒有啟用按鈕。

後續若取得使用者授權，發布流程須：固定草稿版本；由唯讀原版／現用列模板產生新 Client 工作副本與明示管理定價的 Server 配套；保留原件／舊部署／SHA；核對每個請求 tuple、標價、供應及列表一致；保存舊選項的既有領取／歸還功能支援，與新購買供應分開；完成建置、HappyPath 與已排程實機批次後才由管理者明確發布。不能只把新價格寫入 Server，或把舊 source SHA 冒稱成新資源來源。Client 必須完整退出才能更換資源，代理不操作遊戲。

商城配套不是翻譯，仍受 CLIENT-MODIFICATION-POLICY 與 Server AGENTS 的 Client/resource 禁止約束。需使用者另行確認此發布流程可產生及使用商城工作副本；目前只完成提案，不套用 Client 或線上定價。其他獨立開發不因此暫停。

## 驗證

正常草稿建立、改價／列表、版本稽核、回復基準、封存、重開與決定性提案匯出；核對相同遊戲目錄仍按原價購買。獨立 Web Cookie／CSRF 編輯與下載核對。拒絕、衝突／競爭、重送、安全、故障及壓測依既有排程待測。工程／提案匯出不代表配套發布或指定 v2 實機驗收。

## 已完成的草稿功能

Release Host、檢查器與 Web 建置通過；兩項新增正流程及完整既有 HappyPath gate 603／603 通過。驗證了 26 份草稿分頁、改價／列表、回復基準、封存／重開與固定版本匯出 SHA；同一資料庫仍按原 250 購買 2625，沒有用草稿 300 收費。既有回歸保留，不新增退款開發或人工流程。

隔離 Web 以合法 Cookie／CSRF 建立範例草稿並改兩項設定，核對差異、重複下載一致及 SHA header。 [範例提案](example-friends.cash-catalog-proposal.json) 僅示範 2625／250→300 與 2627／列入→移出；不是使用者指定的正式價格。所有套用旗標為 false，SHA 為 `180f3762600817c57bd422883d86c0faf87203ef25f50f4f71e149299f955fe0`。

只換管理端並核對獨立部署的 Web／Character／Persistence SHA、四個主要入口與草稿元件；原遊戲 Host／DLL／四個遊戲埠保留。沒有在實際測試 DB 替使用者建立範例或修改商品價錢，沒有產生 Client 配套檔。工作 Table.stp 與指定 v2 雜湊保持原值。完整收據索引見 [驗證紀錄](cash-catalog-drafts-validation.json)。
