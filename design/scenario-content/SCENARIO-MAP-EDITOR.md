## 資料契約

既有 workbench profile SHA 算法保持，讀取地形不建立草稿或修改範本。
`GET /admin/scenarios/terrain?profile=<既有profileSHA>&map=<map>` 僅回傳該設定已讀地形。
Schema 為 `LOCAL_SCENARIO_STATIC_TERRAIN_V1_NOT_NATIVE_MEF`，欄位包含 `columns`、
`rows`、`worldWidth`、`worldHeight`、`sourceSha256` 與 `blockedBitsBase64`。
編碼 `ROW_MAJOR_LSB_FIRST_BLOCKED_ONE` 按 `row * columns + column`，每 byte
由最低位元開始；1 表示靜態阻擋，0 表示通行，尾端不足 byte 的位元為 0。
最多 2048×2048 格，bitset 最大 524,288 bytes；不傳原 BND 檔或解包成員。

原點、X／Y 軸與 `CanStand` 一致：格列為 X、格行為 Y，世界範圍使用半開區間。
瀏覽器以實際世界長寬比例繪圖、保留完整通行格，不以粗化格替代牆面。
屏障、互動區與傷害區按草稿另畫輪廓，通行格只代表靜態基底。

## 操作與保存

[波次管理](SCENARIO-WAVE-EDITOR.md)另提供順序／定時增援建立、改名、次序、
延遲、旗標及觸發區域，沿用本頁的同一份 JSON、版本及驗證流程。

腳本隨 Web 程式內嵌，頁面以相同 SHA 設定 CSP 與外部腳本 SRI。
只有關卡頁允許該精確腳本與同站地形讀取；其他頁面原政策保持，沒有開放全站
任意腳本、inline script 或 eval。

可選關卡、節點及初始／增援／定時增援的怪物、出生點、出口、互動／區域點、
屏障標記。可用座標欄或點圖移動選取點；怪物另提供模型、PRE、AI 及一般
狩獵場擊殺 EXP。可複製普通怪物再調整，或移除非必要頭目的選取怪物。
必要頭目與每組最後一隻怪物的進階修改仍透過 JSON 並受原驗證器限制。
波次時間、條件、屏障範圍及其他規則保留原欄位，不因圖面編輯而重建或丟棄。

圖面操作先寫入同頁 JSON，狀態明示「尚未保存」。名稱／理由與原表單保存流程
保持，伺服器再次核對來源、圖序、怪物／AI、條件、巡邏與 BND 可達性；
圖面可通行不取代動態屏障或完整路線檢查。保存建立新版本，匯出維持該版位元組。
手動修改 JSON 後，須按「從 JSON 更新圖面」才繼續圖面操作，避免覆蓋未載入的修改。
不相容的歷史來源保持唯讀，不用其他 profile 地形假裝可編。

此功能不自動發布或重啟遊戲、不改 Client／原件／玩家資產。
圖形編排仍不是任意新 Case 註冊、完整三維場景編輯或全部關卡機關的圖形化工具。
