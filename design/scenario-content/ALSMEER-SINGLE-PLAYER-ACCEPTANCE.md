## 主線結算回村的背包

主線結果頁確認後，Server 在回村初始化送出已保存的背包與貨幣。若任務在返回時同時結算 LeeLoo，背包初始化使用該次交易提交後的餘額。背包 `0029` 應在場景就緒 `0024` 前送出。這涵蓋回村後仍有劇情的任務，以及 Q140 直接結算回村的任務。

回村資產快照在主線提交前讀取，讓讀取中斷時仍可重試該主線步驟。回村若同時入帳獎勵，採提交結果的餘額，從資產初始化移除其舊餘額。因此這批回村封包只包含一筆 `002C` 貨幣快照。背包及裝備資料沿用提交前的讀取結果，現行主線結算只改變經驗、主線和貨幣。

原版 BND 離線驗證逐格比對回村背包與 SQLite，並檢查貨幣及送出順序。測試涵蓋兩個全新帳號旅程，分別使用主線基本配置，以及開啟市場、裝備與兩個狩獵場的配置。Q628 長路線亦通過。指定 v2 的回村背包與餘額畫面仍待驗。

主線倒地後的退出按鈕與請求尚待取證。既有 `005D/00` 的證據範圍是隊伍離隊。重登會回廣場並保留已完成的主線，再進村可重開未完成任務。原地復活見 RV-01。

## 本機 TCP 主線驗證

Server 的 `NewAccountReceivesOwnedRolesNamesExpeditionAndReceivesTutorialEntryWithHeartbeat` 正流程從空白 SQLite 建立 KR 帳號，經登入、主連線交接、首次教學、廣場及 Q15，再以同一 TCP 遊戲連線完成 Q117～144。核對兩村的 NPC、33 張主線戰鬥圖、回村載入及羅特魯亞圖 199 的移動和停止。完成後檢查 SQLite 的 Town 3、已完成 22 個接續任務，並用重新取得的應用層租約核對角色與主線存檔。Release 指定測試共 11 個案例通過，其中一個涵蓋此完整主線。角色在這份合成政策下為 Lv.16、245,066 EXP。

這組 TCP 測試採合成可通行碰撞及固定任務經驗政策。原版 BND、一般狩獵場與跨村資產使用下列離線旅程驗證。指定 v2 實機仍依 ST-B01～03 及 SG-B01～03 驗收。
