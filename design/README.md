# Server 設計與回饋（S00）

- [缺口](gaps/index.json)：按 Client 未知 / Server 設計未決 / 衝突 / 測試缺失分類，指明解除條件。
- [設計決策](decisions/index.json)：未來每筆 ADR 應保留比較方案與規範性範圍，後端自訂決策不等於官方規則。

**目前不受理外部回報。** 此為公開 repository，所有提交至此的 FB 都可被第三方看到；不得包含帳號、金鑰、私有程式碼或具敏感性的日誌。未來交接政策另見 `governance/future-feedback/`（未啟用）。
